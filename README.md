# Карта личного времени

Интерактивный архив шести транскриптов астрологического прогноза, названного «2026». Карта соединяет сезоны, жизненные темы, трудности и сильные стороны; каждый тезис открывает дословную цитату с указанием документа и абзаца.

Чёрное звёздное поле, десять пронумерованных зон, тонкие связи и архивная типографика вдохновлены Numogram CCRU и предоставленным визуальным референсом. Это авторская схема навигации по темам, а не вычисленная карта небесных координат или реконструкция натальной карты.

## Периоды

Записи описывают солярный цикл, который заканчивается днём рождения в ноябре 2026. В первом транскрипте указано 3 ноября, а шестой прямо называет октябрь 2026 и прекращает рассмотрение после следующего дня рождения. Начальный ноябрь восстановлен как ноябрь 2025 по последовательности записей; начальный календарный год не назван отдельно. Ноябрь и декабрь 2025 вынесены в «Пролог». Январь и февраль 2026 составляют зимний раздел; ноябрь 2026 покрыт только завершением цикла до дня рождения. Для декабря 2026 и нового цикла 2027 прогноз не заполнен.

Общие описания доступны отдельно от датированных. Начало, середина и конец месяца сохранены словами. Кроме прямо названных рубежей даты не достроены до точных чисел. Астрологические трактовки представлены как содержание записи, без вероятностей и медицинских или финансовых назначений.

## Возможности

- Переход между сезонами и месяцами, общим фоном и новым циклом.
- Выбор темы через зону карты или список, фильтр трудностей и ресурсов, текстовый поиск.
- Исходный фрагмент для каждого тезиса.
- Личные заметки по периоду, локальное сохранение, экспорт и импорт JSON.
- Состояние фильтров в адресе страницы, управление с клавиатуры, адаптация для телефона.

Нет внешних шрифтов, библиотек, аналитики или сетевых запросов. Заметки сохраняются только в браузере и не передаются в репозиторий. Текст прогноза входит в статические файлы и будет доступен посетителям опубликованного сайта.

## Запуск и сборка

Требуется Node.js 22 или новее. Установка зависимостей не нужна.

```bash
npm test
npm run build
```

Открой `index.html` для локального использования. `dist/` содержит готовый сайт, а `astro-calendar.html` — автономный файл со встроенными данными, стилями и кодом.

## GitHub Pages

Создай репозиторий `astro-calendar` в аккаунте `BurangulovRuslan` с основной веткой `main` и загрузите исходники. В Settings → Pages выбери GitHub Actions. Подготовленный workflow проверяет данные и фильтры, собирает `dist/` и публикует сайт. Фактический адрес возвращает успешный шаг Deploy; предполагаемый адрес проекта: `https://burangulovruslan.github.io/astro-calendar/`.

Альтернативно готовое содержимое `dist/` можно разместить в корне ветки и выбрать Deploy from a branch → эта ветка → /(root). Файл `.nojekyll` уже включён.

## Добавление следующей записи

Канонические данные находятся в `data/archive.json`; `data/archive.js` создаётся сборкой. Новая запись ожидается примерно 3 ноября 2026. До получения материала селектор 2027 открывает честный пустой раздел. При добавлении нового цикла потребуются отдельные источники, тезисы и их годовая привязка, после чего нужно расширить фильтрацию года в `app.js` и проверить её тестами. Старый прогноз автоматически не продлевается.
